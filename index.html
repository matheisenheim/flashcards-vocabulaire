📂 Gestion des listes de vocabulaire

Exporte une liste au format JSON, modifie-la (ou alimente-la), puis importe-la. Format : [mot, traduction, catégorie, note, niveau].

Les statistiques sont enregistrées sur ce téléphone. Un mot est compté « lu » quand tu retournes sa carte pour voir la réponse.

Version v21 — installable comme application (PWA)

Dictionnaire français (Larousse)

Pour charger tous les mots, sélectionne ton fichier output.json (celui qui est dans Apprentissage → francais sur Drive, télécharge-le sur le téléphone).
L'importation ne se fait qu'une fois : ensuite les mots restent sur le téléphone, disponibles hors ligne.

Recto : le mot — Verso : définitions, exemples, synonymes. Touche la carte pour la retourner.
